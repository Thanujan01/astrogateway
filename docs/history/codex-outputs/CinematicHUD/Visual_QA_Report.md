# Actual Unity visual QA

All files in Screenshots/ are actual Unity ScreenCapture Game View output. No generated screenshot or static reference overlay. Screenshot_Inventory.json records exact PNG dimensions.

Required scenarios: astronaut full HUD, rover full HUD, map/objectives, deliberately injected resource warning, successful simulated scan, truthful local save status, compact HUD and landscape/notch simulation. Additional four viewport captures show actual 1920×1080, 2340×1080, 2400×1080 and 1600×1200 rendering. Scenario setup uses controlled teleports, source data injection for warnings and the battery-binding test (42%) and actual existing scan/save functions. It is not a human gameplay recording.

Visual inspection checked readable major panels, consistent slate/orange/blue styling, circle joystick, separate menu actions, local-only labels, gray unavailable meters and unobstructed central gameplay framing. The environment and actors remain their existing prototype assets. Reference similarity cannot be graded without the missing user image. Small-font/localized/large-accessibility-text combinations still need broader review.
